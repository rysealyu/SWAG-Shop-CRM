# Team submission checklist

- [ ] Working Google Sheet with persistent dashboard and CRM tabs.
- [ ] Source project in a ZIP or Git repository; no missing dependencies.
- [ ] `README.md` and installation guide for a nontechnical business owner.
- [ ] Script properties `.env.example` / configuration-key guide, with **no secret values**.
- [ ] All Apps Script `.gs` files, HTML if used, and `appsscript.json`.
- [ ] Source-to-CRM extraction contract, validation rules and prompt/skill files.
- [ ] Sample customer email/Excel/PDF import can be rerun without duplicates.
- [ ] 100-message test results with category counts and evidence links.
- [ ] Dashboard day/week/month calculations reconcile to underlying rows.
- [ ] PDF + Excel + image attachment demonstration or explicit capability gap.
- [ ] New email update works from a test Gmail connection.
- [ ] Daily time-trigger installation, manual Sync Now, and Sync Log.
- [ ] Ten grounded personalized drafts, zero actual unapproved sends.
- [ ] Opt-outs excluded; duplicate contact matching is safe.
- [ ] Another user/account can install and run from the submitted package.
- [ ] Disclosure of all optional API/AI/storage fees, quotas, and third-party licenses.
- [ ] Limitations and next steps toward safe production deployment.
